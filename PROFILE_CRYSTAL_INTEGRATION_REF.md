## Что действительно работает

- Настройки → «Палитра кристаллов», отдельная добровольная активация. По умолчанию старый дизайн. Classic остаётся прежним; настройка относится к Aurora.
- 13 пресетов с реальными profile_id из `frontend/src/constants/profiles.ts`. Сами программы/профили не переименованы и не переключаются при выборе оформления. Список/параметры: `flutter/lib/shell/gem_palette_presets.dart`.
- Ещё светлый, чёрный, бледно-розовый бриллианты, сапфир, изумруд, рубин, аметист. Независимые hue, lightness, saturation, backgroundHue и статическое glow.
- Live preview — настоящий Flutter fragment shader. «Применить» сохраняет изменения, возврат без применения не переписывает настройки.
- `psygames_crystal_palette_v1_enabled` — общий выключатель; `psygames_crystal_palette_v1_<profile_id>` — отдельная настройка каждого профиля. При активной функции профиль без ручной настройки получает свой пресет. Состояние уже входит в общий backup/sync namespace SharedState; новый API или миграция не нужны.
- Охват этой версии: шапки **всех пяти корневых вкладок**, закреплённая нижняя навигация и спокойный цвет фоновой поверхности Aurora. Геометрия/центр-слайсы/текст/переходы/пять позиций сохранены. Не объявлять глобальной перекраской всех картинок, игровых полей, предметов и 110+ игровых экранов: это не делалось.
- Тёмный мастер-арт используется и для нейтральных рецептов, поэтому старый кремовый light-пакет с синим запечённым символом не фильтруется неправильно.
- Фикс контраста: на светлом/розовом камне живой заголовок и подписи навигации чёрные. Белый Undo в preview выделен явной отдельной маской; чёрным становится символ, а не все белые блики. Маска механически извлечена из принятой картинки, исходный арт сохранён. Другие незарегистрированные символы не угадываются автоматически.
- При недоступном shader остаётся статический дизайн. В настройках есть честное сообщение и возможность отключить ранее включённый режим. Новые подписи из общего словаря переведены на все12языков; английский остаётся основным.

## Исходники

- `flutter/lib/shell/crystal_palette.dart` — ограниченный валидируемый формат настроек и ThemeExtension, без игровых показателей/учётных данных.
- `flutter/lib/shell/crystal_settings_screen.dart` — настоящее сохранение в SharedState, локализованные контролы, доступность и preview.
- `flutter/lib/shell/gem_palette_material.dart` + `flutter/shaders/gem_palette.frag` — прямой preview и ImageProvider для существующих DecorationImage. Flutter ImageCache кеширует результат по исходнику/масштабу/H/S/L; статическая подложка не перерисовывается shader-ом каждый кадр.
- `flutter/lib/shell/{app_theme,chrome_art,tab_chrome,native_tabs,web_theme,settings_screen,shared_state}.dart` — адресные подключения, без замены старого shell.
- `flutter/assets/palette_pilot/undo-glyph-mask.png`, воспроизведение `flutter/tool/build_palette_glyph_mask.dart`.
- Локализация: `frontend/src/contexts/LanguageContext.tsx` → штатный `node flutter/tools/embed-l10n.mjs` → `flutter/assets/l10n/*.json`.

## Перед выпуском / остаток

1. Перепроверить свежий main, обычный PR и полный CI без ослабления гейтов. При необходимости исправить подтверждённые регрессии небольшими коммитами.
2. Реальное окно: открыть настройки, активировать светлый/розовый пресет, применить, пройти пять вкладок, вернуть другой профиль и отключить палитру. Проверить текст и доступные действия, не только изображение.
3. Выпуск стандартными flutter-testflight.yml (cloud=true, группа «Свои») и flutter-play.yml (cloud=true, production, yes-100), прежний пакет com.psygames.app. Build/upload/VALID/group assignment/Play track readback — разные этапы. Сюда и в TeamOps дописать точные run IDs, версии и квитанции; не считать запуск workflow публикацией.
4. После устройства отдельно оценить память/скорость смены крупных текстур. Для массового переноса окраски на игровые панели/символы сначала нужны собственные маски и контраст соответствующих компонентов; **не применять фильтр ко всему экрану** и не менять цвета правильного ответа, Струпа, воды, фишек или ошибок.

Откат функции — выключатель, без удаления настроек/прогресса. Откат кода — отдельный собственный коммит, не reset чужих рабочих деревьев. Экспериментальные SFX и новые haptics остаются OFF.
