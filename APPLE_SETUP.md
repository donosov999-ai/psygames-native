## Шаг 1. Оплатить Apple Developer Program — 99 $ в год

1. https://developer.apple.com/programs/enroll/ — вход под своим Apple ID.
2. Тип: **Individual** (проще: не нужен D-U-N-S, который для организации делается неделями).
3. Оплата картой. Казахстанская карта проходит; **страна аккаунта Apple ID должна совпадать
   со страной карты** — если аккаунт российский, а карта казахстанская, платёж отклонят.
   Страна меняется в настройках Apple ID до начала оплаты.
4. Подтверждение приходит от нескольких часов до двух суток.

⚠️ Проверять приложение на «нельзя ли обойтись без оплаты» не нужно: без Program не
выдаются ни сертификаты, ни TestFlight, ни загрузка в App Store. Симуляторная сборка,
которая у нас уже собирается, на устройство не ставится.

## Шаг 2. Завести приложение в App Store Connect

1. https://appstoreconnect.apple.com → **My Apps** → **+** → New App.
2. Платформа: iOS. Имя: `PsyGames`. Основной язык: русский.
3. **Bundle ID**: если в списке нет — сначала создать его в
   https://developer.apple.com/account/resources/identifiers → **+** → App IDs → App →
   Bundle ID (Explicit) = `com.odv999.psygames`.
4. SKU: любое своё, например `psygames-001`.

## Шаг 3. Прислать мне четыре вещи

Кладём их в секреты репозитория (Settings → Secrets and variables → Actions). Если не
хочешь возиться — пришли мне, положу сам; но тогда я их увижу, а по нашему правилу
секреты в чат не носим, так что **лучше добавь сам**, а мне скажи «готово».

| секрет | где взять |
|---|---|
| `APPLE_TEAM_ID` | https://developer.apple.com/account → Membership details → Team ID (десять символов) |
| `APPLE_CERTIFICATE` | Xcode → Settings → Accounts → твой Apple ID → Manage Certificates → **+** → Apple Distribution. Затем Keychain Access → найти сертификат → Export → `.p12`. Файл перевести в base64: `base64 -i cert.p12 \| pbcopy` |
| `APPLE_CERTIFICATE_PASSWORD` | пароль, который задашь при экспорте `.p12` |
| `APPLE_SIGNING_IDENTITY` | строка вида `Apple Distribution: Denis Onosov (ABCDE12345)` — её же видно в Keychain Access |
| `APPLE_ID` | почта аккаунта разработчика |
| `APPLE_APP_PASSWORD` | https://appleid.apple.com → Sign-In and Security → App-Specific Passwords → сгенерировать |

## Шаг 4. Дальше делаю я

## Что скорее всего спросит ревью

По опыту приложений этого класса стоит подготовить заранее:

- **Назначение и доказательства.** У нас тренажёры, а не медицина. В описании нельзя
  обещать лечение или улучшение памяти как медицинский эффект — FTC против Lumosity
  (январь 2016, 2 млн $) ровно об этом. Формулировки уже выдержаны в этом духе, но
  описание в App Store я напишу под то же правило.
- **Возрастной рейтинг**: 4+ подходит, азартных механик и рекламы у нас нет.
- **Учётная запись для проверки.** Если ревьюеру нужен вход — дадим профиль без пароля,
  у нас вход не обязателен.
- **Покупки.** Пока их нет — раздел не заполняем; когда появятся, это отдельное ревью.
