### 1.4 🔴 Секунды: обещано 20 → 4, в коде минимум 12
**Чем мерил.** Прогон формулы `Math.max(4, Math.round(20 - (L-1)*0.42))` по всем 40 уровням с надбавками `+4` (L21–30, «защитись») и `+8` (L31–40, «мат в 2–3»).

```
L1  20+0=20    L20 12+0=12    L30  8+4=12    L40  4+8=12
L10 16+0=16    L21 12+4=16    L31  7+8=15
МИНИМУМ по всей лестнице: 12 секунд (впервые на L19). 4 секунды не выдаются НИКОГДА.
```

Заявлено «падают с 20 до 4» и «⚠️ 4 секунды — не «на грани возможного», а замер жанра» в `deck.ts`, в `GAMES_REFERENCE.md` и в тексте игры на ru/en/es/pt. Чистая база доходит до 4, но её всегда перекрывает надбавка.

### 1.8 🔴 `threat` «да» — это ровно позиции `defend`, все 378
**Чем мерил.** `dupes.py`, ключ = первые четыре поля FEN.

```
пересечение defend ∩ threat        : 378 из 378 (100%)
threat «да» ∩ defend               : 378 из 378
threat «нет» ∩ defend              : 0
```

**Механизм в генераторе.** В `out["threat"]` попадают только записи вида `nothreat` (у `rec` тип `defend` уходит в `out["defend"]`). Поэтому `yes = [t for t in thr if t["threat"]]` всегда пуст, и все «да» берутся строкой `defend_as_threat = [dict(d, type="threat", ...) for d in out["defend"].values()]`.

**Последствия.**
1. Блоки «грозит ли» и «защитись» показывают ОДНИ И ТЕ ЖЕ 378 досок. Для упражнения на скорость узнавания это утечка памяти между блоками.
2. На L21–30 оба вида в одной колоде, а ключ дедупликации `${x.kind}:${x.fen}:${x.pre}` включает вид — одна позиция попадает в подход дважды. Замер симуляцией: 8 таких случаев на 200 подходов на L24, 3 на L21, 1 на L27 и L30. Инвариант «🔴 ПОЗИЦИИ НЕ ПОВТОРЯЮТСЯ ВНУТРИ ПОДХОДА» нарушен.
3. Смещение выборки: позиции, где защиты нет вовсе, генератор выбрасывает (`if not sols: return None`) — значит среди «да» нет ни одной неотразимой угрозы, а это самый важный случай.
4. «Нет»-половина набрана другим путём (`if kind == "nothreat" and random.random() > 0.15: continue` — оставлено 15%), то есть половины набора приходят из разных распределений.

### 1.11 237 записанных «спасений» проигрывают
**Чем мерил.** `val_own.mjs` через chess.js (движок приложения), полный перебор.

```
mate    718: записанный ход даёт мат 718/718 | мат в 1 в позиции ЕДИНСТВЕННЫЙ во всех 718
             (распределение числа матов в 1: {1: 718}) | все ходы ферзём на f7/f2
```

**Цена:** новый `kind` в `check.ts` (ответ = поле, куда идёт матующий ход соперника, считается тем же перебором, что уже есть в `естьМатВОдин`); данные берутся из уже скачанного CSV.
