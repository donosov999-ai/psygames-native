# Логотипы Microsoft Store

| файл | размер | назначение |
|---|---|---|
| `box-art-1080.png` | 1080×1080 | 1:1 Box art — **обязателен** для подачи |
| `poster-720x1080.png` | 720×1080 | 2:3 Poster art — рекомендован |
| `poster-source-2k.jpg` | 1696×2528 | исходник постера в 2K, для пересборки под другие размеры |

## Правила, которые здесь соблюдены

**Белого по краям быть не должно.** Иконка приложения имеет запечённое скругление
с БЕЛОЙ заливкой в углах (проверено замером: 255,255,255) плюс собственную глянцевую
светлую кромку. Маска скругления кромку не убирает — она остаётся ободком на фоне.
Поэтому для квадрата применяется ОБРЕЗКА внутрь на 96 точек: уходит и скругление,
и кромка. Проверка: доля почти белых пикселей в box-art = 0.00%.

**Никаких нарисованных кнопок и призывов к действию** («Скачать», стрелки загрузки).
Правила Microsoft это запрещают: человек принимает картинку за живой элемент.

**Никаких обещаний роста интеллекта** («Genius Mind Unlocked» и подобное). В карточке
есть раздел «Честно о науке», где прямо сказано, что перенос на общий интеллект
научно спорен и мы его НЕ обещаем. Обложка не должна противоречить тексту под ней.

**Текст только английский** — постер показывается во всех странах.

## Как пересобрать

```bash
cd frontend && node -e "
const sharp=require('sharp');
sharp('../store/windows/assets/logos/poster-source-2k.jpg')
  .resize(720,1080,{fit:'cover',kernel:'lanczos3'})
  .flatten({background:'#0d0a26'}).png()
  .toFile('../store/windows/assets/logos/poster-720x1080.png');
"
```

## Известное

На исходнике подпись у коллайдера содержит опечатку — «Particle-colllder» с лишней
буквой. Генератор изображений так и выдал. На размере плитки не читается, но при
пересъёмке стоит поправить промптом.
