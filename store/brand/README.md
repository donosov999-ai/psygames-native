# Кандидат новой иконки приложения

`icon-candidate-1024.png` — обрезано из `icon-candidate-2k.jpg` так, чтобы мозг
занимал ~90% квадрата (в исходнике он занимал 77%, вокруг оставалась пустота).

## Сравнение с нынешней — честно

| размер | нынешняя (мозг на оранжево-розовом) | кандидат (мозг на тёмном) |
|---|---|---|
| 32 | силуэт читается: яркий сплошной фон | цветное пятнышко, форма теряется |
| 48 | читается | слабее |
| 64 | читается | сопоставимо |
| 128 | обычная | заметно ярче и дороже |
| 192+ | обычная | сильно выигрывает |

**Где что важно.** 32–48 — панель задач Windows, favicon, мелкие списки.
128–192 и выше — карточка магазина, домашний экран телефона при плотности 3x,
Launchpad на маке. То есть кандидат выигрывает там, где иконку РАССМАТРИВАЮТ,
и проигрывает там, где её узнают боковым зрением.

## Что произойдёт при замене

Меняется в четырёх местах, и все они видны людям:
1. `frontend/assets/images/icon.png` + `adaptive-icon.png` — телефон;
2. `src-tauri/icon-source.png` → пересборка `cargo-tauri icon` — Windows, macOS;
3. `store/appstore/icon-1024-noalpha.png` — App Store;
4. `store/windows/assets/logos/box-art-1080.png` — Microsoft Store.

Замена делается одной командой, но это смена узнаваемого знака:люди, у которых
приложение уже стоит, увидят другой значок. Решение за Денисом.
