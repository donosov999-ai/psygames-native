# Библиотека сгенерированных наборов

Все сетки сохранены целиком — исходники в 4K, ничего не теряется. Из любой можно
нарезать отдельные картинки скриптом внизу.

## Что есть

| файл | что внутри | стиль |
|---|---|---|
| `app-icons-20.png` | 20 значков приложения | объёмные, светящиеся, тёмный фон |
| `app-icons-25.jpg` | 25 значков приложения | плоские, яркие фоны, читаются мелко |
| `app-icon-cinematic-single.jpg` | 1 значок крупно | мозг с молниями и чипами |
| `profile-icons-objects.png` | 12 значков профилей | плоский мультик, мозг + предмет |
| `profile-icons-people.jpg` | 12 значков профилей | плоский мультик, человек + мозг |
| `profile-brains-cinematic.jpg` | 12 значков профилей | кинематографический, мозг + свет |
| `profile-people-cinematic.jpg` | 12 значков профилей | кинематографический, портреты людей |

Порядок клеток во ВСЕХ сетках профилей одинаков:
ODV999 · Шахматист · Дети · Скорочтение · НЗТ-48 · Стандарт ·
Реакция · 50+ · Предприниматели · Студенты · Микро-релакс · Полиглот

## Куда что просится

**`profile-people-cinematic` → аватары профилей.** Имя профиля называет ЧЕЛОВЕКА
(«Дети», «50+», «Предприниматели»), и портрет отвечает на этот вопрос сразу.
Мозг на его месте отвечает на другой вопрос — «про что приложение», — а это человек
и так знает. Ставить в переключатель профилей, где плитки крупные.

**`profile-brains-cinematic` → мелкие места того же профиля.** Чип профиля в шапке,
строки списков: там 32–44 точки, портрет превращается в кашу, а силуэт мозга ещё
читается. Наборы совместимы: порядок один, берётся по размеру.

**`app-icons-20` → набор «мозги» для парных картинок.** Уже сделано: 12 из 20 лежат
в `frontend/assets/images/pairs_brain/`, тема отдана профилю НЗТ-48. Оставшиеся 8 —
запас на второй набор или на «Найди отличия».

**`app-icons-25` → аватары магазина.** Сейчас там 9 штук по 256×256, покупаются за
очки. 25 разных мозгов — готовая ветка косметики, причём тематически своя, а не
случайные животные. Плоские яркие как раз для мелкого аватара в чипе.

**`profile-icons-objects` → карточки категорий или значки достижений.** Мозг с
предметом читается как пиктограмма и не спорит с портретами профилей.

## Как нарезать любую сетку

```bash
cd frontend && node -e "
const sharp=require('sharp'), fs=require('fs');
const SRC='../store/brand/icon-sets/ИМЯ.jpg', OUT='/tmp/sliced', COLS=4, ROWS=3;
(async()=>{ fs.mkdirSync(OUT,{recursive:true});
  const m=await sharp(SRC).metadata();
  const cw=Math.floor(m.width/COLS), ch=Math.floor(m.height/ROWS), pad=Math.round(cw*0.03);
  let n=0;
  for(let r=0;r<ROWS;r++) for(let c=0;c<COLS;c++){ n++;
    const side=Math.min(cw,ch)-pad*2;
    await sharp(SRC).extract({left:c*cw+pad, top:r*ch+pad, width:side, height:side})
      .resize(256,256,{kernel:'lanczos3'}).webp({quality:88})
      .toFile(OUT+'/'+String(n).padStart(2,'0')+'.webp'); }
  console.log('нарезано', n);
})();
"
```

## Правило, которое стоило кредитов

Генерировать **сеткой в одной картинке**, а не по одной штуке: 20 вариантов в сетке
стоят 18 кредитов, поштучно — 160. Разница в девять раз. Промпт должен явно задавать
число столбцов и строк и запрещать любые надписи внутри картинки.
