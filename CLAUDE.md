## 🔴 Три файла, на которые равняются все

| файл | что в нём | когда обязателен |
|---|---|---|
| **`UI_LAYOUT_RULES.md`** | **ЗАКОН расположения экрана игры**: шапка, показатели, поле, низ, стрелки, кнопки, цифры. Правила с замерами; счёт держит сам файл (§2) — не дублировать числом здесь, оно уже дважды протухло | **перед любой правкой вида игры** |
| `CHATS_RULES.md` | правила работы чатов-разделов; главнее любого `SPEC_CHAT_*.md` | первый заход и при спорах |
| `PLATFORM_AND_RENDERING_FACTS.md` | что установлено и что ОПРОВЕРГНУТО про платформу и рисование | перед разговором о движках, весе, анимациях |

🔴 **`UI_LAYOUT_RULES.md` — это стандарт, а не совет.** Он существует потому, что
разделы лепили по-разному и не знали, к чему ровняться: полоса показателей то 61,
то 13, служебный ряд то под полем, то над ним, поле уезжало за край, стрелки стояли
строкой вместо крестовины. Каждое расхождение стоило отдельного разбора.

Числа берутся ТОЛЬКО из `frontend/src/components/gameLayout.ts`. Файл правил
объясняет почему; копировать числа из него в свой модуль нельзя — так они и
разъезжались.

Сопутствующее: `SPEC_SCREEN_GEOMETRY.md` — ОТЧЁТ ЗАМЕРА (кто на каноне, кто отходит),
он устаревает; закон — в `UI_LAYOUT_RULES.md`, он меняется только решением.

## Что это за проект

React Native + Expo Router. 🔴 **Но на устройство едет НЕ нативный RN, а веб-сборка
внутри Tauri-WebView:** все платформы собираются `npx expo export -p web` →
`cargo tauri build`, папок `frontend/ios` и `frontend/android` не существует.
Отсюда: Fabric у нас не выполняется, нативные RN-библиотеки неприменимы, iOS — это
WKWebView (WebKit), Android — Chromium. Подробно и с замерами —
`PLATFORM_AND_RENDERING_FACTS.md`.

## Горячие грабли — стоили круга сборки или выпуска

| грабля | как не наступить |
|---|---|
| Новая игра трогает **семь общих реестров**, а не четыре | список знает только полный прогон `npx jest src/__tests__` |
| `bottom="actions"` без правки `slot-meaning.test.ts` | правится ОДНИМ коммитом, иначе гейт `slot` останавливает выпуск |
| Зелёный гейт ≠ приёмка | открыть и **сыграть**; для жестов и прокрутки — только на устройстве |
| Настольный Chromium ≠ iPhone | у WebKit своя резинка-оттяжка; Safari на столе ≠ установленный WKWebView |
| `useNativeDriver: true` | на нашей платформе молча откатывается в JS: нативного модуля анимации в WebView нет |
| Признак ≠ замер | `grep`, `npm ls`, число строк и узлов — признаки. Замер отвечает «сколько это стоит в том, что исполняется» |
| `git add -A` | запрещён: в общем дереве чужое лежит в индексе ДО тебя. Только `git commit -- <пути>` |

## Порядок правки

1. `git pull --rebase` перед работой, свой `worktree` — общее дерево не переключать.
2. Замер ДО числом → правка → гейт, краснеющий на возврате дефекта → замер ПОСЛЕ.
3. Гейт доказывается **мутацией**: верни дефект — проба обязана покраснеть.
4. Общий слой (`constants/games.ts`, `hubContents.ts`, `gameSuites.ts`, `profiles.ts`,
   `helpMap.ts`, версии, метки) — через координатора `psygames-claude-mac`.
5. Версию не поднимать, метку не ставить, выпуск не собирать — это координатор.

## Отказ требует такого же замера, что и согласие

Под «нечего брать», «дефекта нет», «не подходит» обязаны стоять: чем мерил (команда,
файл, строка) · что получилось (число) · что из отклонённого ВСЁ РАВНО переносится.
