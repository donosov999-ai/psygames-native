## 1. Установлено замером

Каждая строка — с тем, ЧЕМ померено. Без этого строка сюда не попадает.

### 1.1. 🔴 Мы не React Native на устройстве. Мы веб внутри WebView

```
.github/workflows/build.yml — семь мест: npx expo export -p web
src-tauri/tauri.conf.json   — "frontendDist": "./dist"
Android и iOS               — cargo tauri android build / cargo tauri ios build
папок frontend/ios и frontend/android НЕ СУЩЕСТВУЕТ
```

Все платформенные сборки идут одним путём: экспорт в веб, потом Tauri. Нативного
RN-проекта в репозитории нет.

**Следствия, которые меняют весь разговор о движках:**
* Fabric и «новая архитектура» у нас **не выполняются никогда** — значит цена
  «перевести 99 экранов на новую архитектуру» не существует;
* нативные RN-библиотеки неприменимы ВСЕ: Skia native, `react-native-filament`,
  `expo-gl`/R3F. Не «не измерено», а не может работать в нашей модели поставки;
* iOS WebView = **WKWebView (WebKit)**, Android = Chromium. Значит «проверить в
  Safari» — не дополнительная галочка, а профильная среда для половины людей;
* нам доступен весь веб напрямую: `three.js` у нас — это просто `three.js`, без
  моста RN и без новых RN-зависимостей.

⚠️ **Оговорка Кодекса, принята:** это факт КОНФИГУРАЦИИ, а не доказательство
успешной установки и работы на устройстве. Приёмка на iPhone — отдельно.

### 1.2. 25 вызовов `useNativeDriver: true` мертвы

Источник — исходник самой библиотеки, не грep по нашему коду:
`node_modules/react-native-web/dist/vendor/react-native/Animated/NativeAnimatedHelper.js:404-416`

```js
if (config.useNativeDriver === true && !NativeAnimatedModule) {
  console.warn('...Falling back to JS-based animation...');
  return false;
}
```

Нативного модуля анимации в WebView нет, поэтому все 25 откатываются в JS-поток.
Предупреждение печатается ОДИН раз за сессию и тонет в логе.

⚠️ Это факт о коде, **а не замер тормозов**. Что именно тормозит и тормозит ли —
отдельный вопрос с профилем кадра.

## 2. 🔴 Опровергнуто — не возвращаться

Каждое из этих утверждений звучало убедительно и было названо вслух. Каждое
опровергнуто замером. Если следующий заход выведет их снова — он повторяет
пройденный путь.

| утверждение | кто опроверг | чем |
|---|---|---|
| «Ментальная ротация показывает готовые ракурсы, плавного вращения нет» | чат ротации | `surface.ts` считает тригонометрию по дробному углу на каждом кадре |
| «Мы на старой архитектуре → конфликт с reanimated 4» | Кодекс, затем координатор | вывод по флагу `newArchEnabled` неверен; глубже — архитектура вообще нерелевантна, нативный RN не исполняется |
| «reanimated надо выкинуть» | Кодекс | `npm ls` показывает объявленные зависимости, а не исполняемый код; удаление требует алиаса И runtime-приёмки |
| «reanimated надо начать использовать» | координатор сам | на вебе нет отдельного UI-потока, ради которого она существует |
| «Skia — миграция всего, Three.js — один экран» | Кодекс | точечно подключается и то и другое; противопоставление ложное |
| «Нет `<canvas>` — значит нет GPU» | Кодекс | DOM и SVG тоже участвуют в аппаратном рендеринге и композиции |
| «CSS `transform`/`opacity` уйдут на композитор» | Кодекс | «могут», не «уйдут». Нужна декларативная CSS/WAAPI-анимация и проверка в Safari. Если JS задаёт трансформацию каждый кадр — зависимость от главного потока остаётся |
| «Раннер невозможен без нового движка» | Кодекс | не проверено; сравнивать конкретную сцену: глубину, перекрытия, камеру, нагрузку — а не жанр |
| «expo-gl/R3F не годятся, Apple похоронила OpenGL» | координатор | к нам не относится: у нас WebGL в WebView, а не нативный OpenGL |
| «filament — веб не измерен, скорее всего нет» | координатор | сильнее: он не может работать в нашей модели поставки вовсе |
| «1300 строк костылей вместо движка» | чат ротации | из них 889 — работающий софт-рендерер с геометрией; «строки» не доказывают ни отсутствия функции, ни медленности |

## 3. Правила спора, выработанные этим разбором

Они дороже любого вывода выше, потому что применимы ко всему.

1. **Признак ≠ замер.** `grep`, `npm ls`, число строк, число узлов DOM, число
   вхождений в бандл — это признаки. Замер отвечает на вопрос «сколько это стоит
   в том, что исполняется». Координатор за один день трижды подал признак как
   доказательство — и трижды был поправлен.
2. **Успешная сборка ≠ безопасная экономия.** Алиас на пустышку собрался — это
   диагностика. Пока не прогнаны переходы, drawer и ленивые экраны, разница байтов
   ничего не разрешает.
3. **Настольный стенд ≠ iPhone. Safari ≠ установленный WKWebView.** Viewport
   размером с телефон не делает замер телефонным.
4. **«X невозможен без Y» проверяется сценой, а не жанром.** Требования называть
   поимённо: глубина, перекрытия, движение камеры, число объектов, нагрузка.
5. **Опровержение одного довода не отменяет остальных.** Три цифры из четырёх
   сошлись — соглашаться пакетом всё равно нельзя, и проверять надо ту, что ближе
   к твоей зоне.
6. **Отключённая анимация — не ускорение.** Сравнивая рендереры, сверять
   промежуточные кадры, а не только конечный.

## 5. Чего этот файл НЕ решает

Он не выбирает движок. Ни Three.js, ни CanvasKit, ни SVG не объявлены
победителями — прототип раннера подтвердит пригодность Three.js для ОДНОЙ сцены и
не докажет превосходства над альтернативами. Решение принимается по работающим
сценам и замеру на iPhone, а не по количеству флагов, импортов и строк.
