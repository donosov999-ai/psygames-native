## Как снята выборка

Корпус — 304 МБ в сжатом виде, 2 385 370 задач. В приложение он не помещается, поэтому берётся выборка:
каждая 311-я строка (простое число — выборка размазана по всему файлу), затем квота 400 позиций на каждую
полосу по числу фигур: 4–8, 9–14, 15–20, 21–26, 27–32. Итого 2000 позиций, 188 КБ.

## Почему полоса по числу фигур, а не рейтинг

Число фигур — это ОБЩИЙ параметр уровня для всех трёх блоков серии (см. `PSYGAMES_MERGE_PLAN.md` §21.1):
оно задаёт нагрузку и блоку памяти, и выбору полей. Рейтинг Lichess лежит рядом вторым признаком —
он про трудность ТАКТИЧЕСКОЙ задачи, а мы задачу не решаем, мы запоминаем позицию.

## Почему реальные позиции, а не случайная расстановка

На случайно расставленных фигурах преимущество опытного игрока ИСЧЕЗАЕТ — именно поэтому случайная
расстановка используется как контрольное условие. Меряя память на ней, игра меряла бы голый
зрительно-пространственный объём, то есть дублировала бы «Клетки» и «Матрицу памяти».
