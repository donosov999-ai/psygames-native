## 1. `src/constants/games.ts` — запись для `GAMES`

Класть в блок `// ATTENTION`, рядом с `schulte_table` / `visual_search`.

```ts
  {
    id: 'object_tracker',
    nameKey: 'objectTracker',
    descKey: 'objectTrackerDesc',
    skillKey: 'skillAttention',
    gradient: ['#f59e0b', '#7c3aed'],
    icon: 'radio-button-on',
    route: '/games/object-tracker',
    category: 'attention',
  },
```

- `category: 'attention'` — multiple object tracking это ёмкость внимания, а не
  память и не логика. Соседи по категории (Шульте, корректура, поиск отличий)
  тренируют внимание к **неподвижному**; здесь единственное в каталоге внимание к
  **движущемуся**, и категория от этого не размывается, а достраивается.
- Градиент `#f59e0b → #7c3aed` — тот же, что уже зашит в экране (`GRADIENT`).
  Менять здесь, не поменяв в экране, нельзя: снаружи карточка и внутри игра станут
  разного цвета. Одним сплошным цветом текст поверх него AA не берёт — на плашке
  стоит `GradientSurface`, он кладёт вуаль сам.
- `skillKey: 'skillAttention'` («Тренируем: концентрацию») — ключ уже существует,
  новый заводить не нужно.

**После добавления записи убрать строку `'object-tracker'` из `AWAITING_CATALOG`
в `src/__tests__/game-routes.test.ts`** — там же стоит проверка, которая покраснеет
на протухшем исключении, так что забыть не дадут.

## 3. `src/constants/helpMap.ts`

Карта генерируется `scripts/gen-helpmap.mjs` — правильный путь перегенерировать её
после п. 1–2. Если руками, запись такая:

```json
  "/games/object-tracker": {
    "nameKey": "objectTracker",
    "gameId": "object_tracker",
    "introKey": "objectTrackerIntroDesc"
  },
```

Без неё кнопка «?» на экране игры не рисуется вовсе (`GameHelpOverlay` возвращает
`null`, когда маршрута нет в карте). Гейт `help-map` держит долг на нуле, так что
без этой записи прогон покраснеет сразу после п. 1.

## 5. `src/services/api.ts` — `DETAILS_SCHEMAS`

Схема непроверяющая (лишние поля она не запрещает), нужна ради предупреждений о
пропавших числах:

```ts
  object_tracker:    { level: 'number', accuracy: 'number', hits: 'number', misses: 'number', false_selections: 'number', close_approaches: 'number' },
```

Экран уже пишет полный набор: `level`, `accuracy`, `object_count`, `target_count`,
`hits`, `misses`, `false_selections`, `close_approaches`, `motion_duration_ms`,
`reduced_motion`, `seed`, `generator_version`.

`close_approaches` — сколько раз за раунд объекты сходились вплотную. Без него
«ошибся» и «было объективно тесно» выглядят в статистике одинаково, а это разные
вещи: теснота задаётся уровнем, а не человеком.

## 7. Зарядка (`src/services/warmup.ts`) — нужна ли и с какой сложностью

**Да, в утренний и дневной пул. В вечерний и ночной — нет.**

Причина не вкусовая: раунд идёт «показ → движение → выбор», и всё это время держать
внимание нельзя вполглаза — упражнение либо делается собранно, либо не делается
вовсе. Вечерний слот помечается `calm=1` и существует ровно для обратного:
успокоиться перед сном. Экран `calm` честно отрабатывает (`useCalmHush` глушит
звук), но нагрузку никакой флаг не уберёт.

```ts
    { game_id: 'object_tracker', game_route: '/games/object-tracker', difficulty: 'medium', settings: { level: 9 }, est_duration_sec: 60 },
```

- `level: 9` для `medium` — две цели из 6–9 объектов: уже не «следи за одним», но
  ещё без перегруза. Для `easy` — `level: 3`, для `hard` — `level: 25`.
- `est_duration_sec: 60` — движение по уровню занимает 3.6–5.4 с, остальное показ
  и выбор; выбор не ограничен по времени, минуты человеку хватает с запасом.
- ⚠️ Шаг зарядки уровень не двигает (`isPreset` в экране), это общее правило.
- ⚠️ **В щадящем режиме шаг зарядки идёт дольше**: движение проходится нажатиями по
  250 мс, на 9-м уровне это ~14 нажатий. Если для зарядки важна предсказуемая
  длительность — брать уровень пониже, а не резать шаг.
