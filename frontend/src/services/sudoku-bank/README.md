## Зачем банк, если у нас есть генератор

Замер 23.08.2026, по 3 доски на уровень:

| уровень | цель по ступени | что выдал генератор | мимо |
|---|---|---|---|
| L35 | 4–5 | 5, 5, 4 | 0/3 |
| **L40** | **5–6** | **4, 3, 4** | **3/3** |
| **L45** | **6–6** | **4, 4, 3** | **3/3** |
| **L53** | **6–6** | **3, 4, 3** | **3/3** |
| **L57** | **6–6** | **3, 4, 4** | **3/3** |

**48% досок не попадают в свою ступень**, и промах не случаен: всё, что просит пятую ступень и выше, проваливается целиком — генератор упирается в четвёртую. Человек на 53-м уровне играет доску уровня 25-го. На неудачу при этом уходит весь бюджет сборки, 4,4 секунды.

Банк снимает это по построению: доска не мелется, а выбирается по известному рейтингу.

## Чего банк НЕ закрывает

Только классика 9×9. Наши варианты — диагональ, джигсо, термометр, стрелки, сэндвич, киллер — в банке не лежат, для них генерация остаётся своей. Оценщик техник тоже не выбрасывается: он нужен, чтобы показать человеку, КАКАЯ техника здесь работает, — это обучение, а не назначение сложности.

## Проверено при закладке

Каждая из 1835 досок прогнана независимым перебором: **1835 с ровно одним решением, 0 с несколькими, 0 противоречивых.** Подсказок 23–37, медиана 28.
